Source Serif 4 roman and italic variable fonts are from the [Google Fonts repository](https://github.com/google/fonts/tree/08dc85da6bca7ae308a6f1d38d0b137465646071/ofl/sourceserif4), distributed under the accompanying SIL Open Font License 1.1. They cover weights 200–900 and retain the family’s language coverage. Local files avoid build-time dependence on the Google Fonts CSS response.
